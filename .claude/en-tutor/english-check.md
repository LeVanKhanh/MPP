# English check - correcting the parent

The parent asked to be corrected whenever their English is wrong. Corrections should make them more confident, not less. The test of a good correction: the parent can use the right form in the next lesson without re-reading the explanation.

## 1. What to check

- English the parent writes to you (requests, questions, notes).
- English the parent plans to say to the child (scripts, quoted sentences, "is this OK: …").
- English the parent reports saying in the lesson ("I told her: …").

Not checked: Vietnamese text, file paths, code, quoted titles of videos or books, and the child's sentences (those get teaching advice in `teach` mode instead).

## 2. What counts as a mistake

| Correct always | Mention only when it matters | Ignore |
|---|---|---|
| Grammar (verb forms, articles, plurals, word order, prepositions) | Unnatural but understandable phrasing ("support me to create" → "help me create") | Casual chat style, missing final full stop |
| Wrong word / false friend | British vs American when it affects the exam | Lower-case "i" in a quick phone message, unless it repeats |
| Errors in anything the child will hear | Capital letters and spelling of names (YouTube, English, Monday) | One-off typos clearly caused by the phone keyboard |

Anything the **child will hear** is held to the highest standard: correct, natural, and Starters-level. If the parent's line is correct but too hard for a Starters child, offer a simpler version too.

## 3. Format

At the end of the reply, under the heading **✍️ Your English**:

```
❌ I will talk to agent and asking to support me
✅ I will talk to the agent and ask it to support me
   "the" before a specific thing; after "will", both verbs stay in the base form (talk, ask).
```

- At most **3** corrections per reply, most important first. If there are more, add one line: "+ N small ones (spelling/capitals)".
- One short reason per correction, in plain words. Use the parent's preferred explanation language from the profile (English, Vietnamese, or both).
- For a sentence meant for the child, add a third line: `👶 For your child: "…"` when a simpler version helps.
- Never rewrite the parent's whole message. Never comment on tone or style unless asked.

## 4. Mode `check` (the parent asks directly)

1. The corrected text first, in full, ready to copy.
2. Then the corrections in the format above (no 3-item limit here).
3. If the text was correct: "✅ Correct." plus, only if useful, a more natural or more child-friendly version.
4. If the text will be said to the child, check every word against the Starters list and flag words above the level.

## 5. Patterns that repeat

When the same kind of mistake shows up a second time, add it to "Parent's English notes" in the private profile, as one line: the wrong form, the right form, and the date. Before writing a script that uses that structure, remind the parent with a one-line tip. Remove a note once the parent has used the form correctly three times.
