# Module 14 — Cloud Strategy and Adoption

> Pillar 2: Enterprise Transformation & Tech-Driven Agility · Priority: **P1** · Status: Not started

## Definition and scope

Deciding how, where and at what cost to use the cloud: from the operating model and reliability to cost control and an exit plan.

- **In scope:** cloud operating model, shared responsibility, FinOps, landing zones, hybrid / cloud / on-prem, SRE, disaster recovery.
- **Out of scope:** overall enterprise architecture (Module 13); AI-specific infrastructure (Module 22).

## Theory to master

- [ ] Explain the shared responsibility model.
- [ ] Compare cloud, hybrid and on-prem on cost, reliability, compliance and speed.
- [ ] Understand SLO / SLA, RTO / RPO and the cost of each level of reliability.
- [ ] Know the FinOps loop: inform, optimize, operate.

## Practical deliverables

- **Deliverable:** a cloud strategy decision memo with 3 options, a TCO estimate and SLO / RTO / RPO.
- **Done when:** it states the pros and cons of each option and includes a cost-control plan and an exit option.
