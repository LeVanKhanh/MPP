# Module 16 — Managing and Implementing Complex Projects

> Pillar 2: Enterprise Transformation & Tech-Driven Agility · Priority: **P1** · Status: Not started

## Definition and scope

Running programmes with many workstreams, many dependencies and limited resources, so that value actually reaches users.

- **In scope:** programme governance, dependency management, critical path, portfolio execution, progressive delivery, benefits tracking, decision logs.
- **Out of scope:** choosing which projects get done (Module 05); measuring strategic value after delivery (Capstone).

## Theory to master

- [ ] Tell project, programme and portfolio apart.
- [ ] Manage dependencies between workstreams and find the critical path.
- [ ] Understand progressive delivery: small releases with rollback.
- [ ] Track benefits, not just progress.

## Practical deliverables

- **Deliverable:** a multi-workstream transformation programme plan: resource constraints, milestones, rollback strategy, decision log.
- **Done when:** there is a mechanism for handling delays, and scope / time / value / risk trade-off rules are defined in advance.
