# Module 20 — Artificial Intelligence (AI) and Machine Learning (ML) Strategies and Frameworks

> Pillar 3: Leading AI, GenAI & Frontier Technologies · Priority: **P1** · Status: Not started

## Definition and scope

A framework for deciding which problems need ML, GenAI, ordinary automation or no AI at all, and for managing the model lifecycle afterwards.

- **In scope:** ML problem framing, training vs inference, evaluation, model risk, use-case prioritisation, model lifecycle, data readiness.
- **Out of scope:** business-level AI strategy (Module 03); neural network technical detail (Module 21).

## Theory to master

- [ ] Frame a business problem as an ML problem (inputs, outputs, metric).
- [ ] Tell training and inference apart in cost and operations.
- [ ] Know how to evaluate a model and the types of model risk.
- [ ] Assess data readiness before starting.

## Practical deliverables

- **Deliverable:** an AI opportunity assessment of 5 use cases, scoring impact, readiness, risk and operating cost.
- **Done when:** each use case has a clear decision: ML, GenAI, deterministic automation, or no AI.
